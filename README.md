# Description

These are my personal configurations for many commands and bash

## Important files/folders

- vim:
    1. .vimrc: main vim configuration;
    2. .vim-inputrc: vim mappings;
    3. .vim-colors: color schemes;
    4. .vim/:
        - snippets/: language specific auto-inserts (snippets);

- .bash_*:
    1. .bash_aliases: all aliases, settings-like for commands;
    2. .bash_functions: custom in-house functions;
    3. .bashrc → .bash_profile;
    4. .bash_shopts: shopt options for bash;

## Miscellaneous files/folders

- .lesskey: less' input settings;
- .gitconfig;
- .inputrc: readline's config;
- .lynxrc;

- .git-custom-commands/:
    command scripts that mainly address
    missing functionality from git from time to time;
